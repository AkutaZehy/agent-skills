# Publish Privacy Alert

对外发布前的内容隐私卫生审查。方法论核心是**数据与逻辑分离**：本 skill（公开、通用、无任何真实实例）只装检测方法与流程；真实标识（路径、主机名、邮箱、派生标识）全部住在本地机器画像文件里，永不进入公开仓库。

## 先读：装了本 skill ≠ 防泄露万事大吉

本 skill 把核对从"记忆召回 + 模型自觉"变成结构化步骤，但它不提供绝对保证。已知盲区（不完整清单）：

- 确定性扫描只覆盖画像与内置模式里的**已知形态**；新的转义变体、新的编码方式、语义组合（多条无害信息拼出敏感画像）都在扫描器原理盲区里。
- 语义层核对（第三方权利、画像外可疑串）的质量取决于执行者；脚本对本层无能为力。
- 画像会过期：新设备、新别名、新服务出现时，过期画像就是新盲区——画像需要随环境变化持续维护。
- 文件 symlink 会被跟随并扫描；未解析的 symlink 记扫描错误（exit 6），不静默跳过；目录 symlink 不展开，发布树内的目录 symlink 指向需人工确认。

每次对外发布的最终判断，始终是**人 + 流程**的责任。

## 与 magpie 出站脱敏的边界

magpie 的 Privacy masking（`redact`）在本机常开。2026-10-27 实测：网关 v0.1.1668、`~/.config/magpie/settings.json` 的 `"redact": true`、`~/.config/magpie/masking/` 有逐请求记录（66 条、329 个值，类别 SECRET / API_KEY / TOKEN）、脱敏服务不可用时返回 503 而不发送。它做的是**值级、可逆、出站**替换：API key、私钥、token、邮箱、带校验和的卡号与证件号换成占位符，回复里再还原。

边界：它覆盖经过该网关的流量，`git push` 不经过；它认凭据与 PII 值，盘符路径、主机名、派生 ID 与第三方版权不在其检测面；它不改文件。发布树级判定由本 skill 的画像扫描与人工核对承担，两者各自独立，不可互相替代。

复核方法：看 `~/.config/magpie/settings.json` 的 `redact` 与 `~/.config/magpie/masking/*.jsonl` 的记录条数与类别。

## 审查范畴（四类必审）

| 类别 | 内容（通用描述） |
|---|---|
| 身份与联系方式 | 真实姓名、私人邮箱、手机号、住址/位置、实名账号 |
| 凭据与密钥 | API key、token、密码、私钥、内网凭据 |
| 基础设施拓扑 | 本机盘符路径（含转义变体）、主机名、内网地址、代理端点与上游组合 |
| 第三方权利 | 他人版权代码（许可不兼容）、他人隐私与内部信息、许可冲突 |

**豁免**：工具画像、过程叙事、技术品味、个性表达放行——这些是作者个性与魅力的组成部分，不在审查范围。

## 机器画像（数据契约）

扫描前先加载本地画像文件，约定路径 `~/.config/agent/publish-profile.md`（格式见该文件头注释）。本机已使用此画像；其他 harness 复用同一文件，不复制画像内容到 skill 或仓库。**画像缺失或为空时，先与用户共建画像，再执行扫描**——画像缺失的扫描等于没扫。

画像条目前缀约定：字面量直接写（按固定字符串匹配）；`re:` 前缀 = 正则；`allow:` 前缀 = 已批准形式（命中降级为放行并标注）。

## 流程

1. **加载画像**：缺失即先与用户共建。
2. **确定性扫描**：用 bash 执行本 skill 目录下的 `scripts/scan.sh <画像文件> <目标路径或文件>...`；Windows 上使用可用的 Git Bash 或 WSL，并按该运行环境传入文件路径。输出默认脱敏（文件:行 + 分类标记，不打印原文）；allow 命中标为 `[allow-candidate]` 转人工裁决，不静默吞掉。扫描自动排除 `.git` 与 `node_modules`，文件 symlink 会被跟随并扫描，未解析的 symlink 记 exit 6；目录 symlink 不展开，发布树内的目录 symlink 指向需人工确认。退出码即结论：`0=CLEAN`、`1=HIT`、`2=用法`、`3=画像缺失`、`4=画像无效`、`5=目标缺失`、`6=扫描错误`——**任何非零都不得当作 clean，任何无法确认已扫描的状态都必须非零退出**。
3. **命中三值分类**：放行（命中允许清单或合成向量）/ 修改（洗成占位符或相对路径）/ 轮换（曾真实存在的凭据，删除之外必须换新）。
4. **语义复核**：按四类核对表逐文件过——重点第三方权利，以及画像外可疑串（读起来像真实文件系统布局、真实服务、真实日程的字符串）。
5. **最终交付物终扫**：对真正的发布物执行——npm 包解包扫、构建产物扫、release notes 逐句读。工作树干净不代表交付物干净。

## 放行白名单（通用占位符）

相对路径；模拟路径（`C:\demo`、`C:\path\to\your`、`/tmp/example`）；尖括号占位符（`<name>`、`<your-key>`）；文档保留域名（example.com）；合成测试向量。命中白名单 = 放行并记录，不阻塞发布。

## 依赖

bash（3.2+）、`find`、`grep`（`-n -I -F -E -f`）、`sed -E`、`mktemp`。Windows 需 Git Bash 或 WSL。扫描器自持输出格式（find 枚举 + 逐文件 grep），GNU grep / BSD grep / ugrep 均可；画像文件兼容 LF 与 CRLF。
