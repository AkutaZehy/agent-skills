# ask-first

给编码 agent（ZCode / Claude Code 等 SKILL.md 类 harness）的反问协议 v2。核心主张一句话：**把"考虑要不要问"换成"考虑问什么"——开工就亮出任务类型、完成口径和反问批次，好过把思考变成没有出口的搜索。**

本项目由 GLM-5.3-Flash 构建。

## 为什么是 v2（两轮 rollout 实测）

1. **2026-09-23**：约 565 万字思维链扫描发现，"Better:/Simpler:" 型冒号提议出现后约 85% 被采纳（最该盯的换方案信号），而看着最危险的 "what if / how about" 约 78% 是自检疑问；一次实测里语义换手 3 次、模型自报 0 次。
2. **2026-09-28 复盘**：v1 的在飞翻转计数器（思维里维护 tally 行）装入后 5 天，反问 0 次、计数行只出现 3 次且是收尾汇报式回声——**模型对"正在进行的思考"做可靠的语义自计是不可执行的**，规则在场不等于触发。v2 因此把触发从模型内挪到任务结构上：开工三件套、读→改漂移闸门、可选的外置 hook 闸门（见下）。

思考语言因模型而异（GLM 中文思考多，MiMo/DeepSeek 全英文思考），所以 SKILL.md 内含 English 与 中文 两个等价版本。

## 安装

```bash
# 脚本方式（含 AGENTS.md 模板打印与可选闸门安装）
./install.sh --zcode --hooks     # 仓库根目录；--hooks 装 ZCode 结构闸门，可省略

# 手动方式
cp skills/ask-first/SKILL.md ~/.zcode/skills/ask-first/SKILL.md
cp skills/ask-first/SKILL.md ~/.claude/skills/ask-first/SKILL.md
```

行为规则需要每次会话在场：把 [templates/ask-first.md](../../templates/ask-first.md)（开工三件套整段）贴进用户级 AGENTS.md / CLAUDE.md。想要结构化提醒（开工、第一次落笔、收尾三个时刻注入，软规则之外多一道闸）就加 `--hooks`，仅 ZCode 支持。

## 协议摘要

开工三件套（编码/修改与环境/排障强制；检索、只读、纯对话豁免批次）：类型（读/改/读并改/检索/计划/描述+对象；先数任务数，一条消息可含多任务）、Done when 口径、一次 AskUserQuestion 反问批次（题目只锚定口径确认与真实分叉，grep 能答的先自查）。漂移闸门：声明为读的任务第一次落笔修改即视为"读并改"，补批次或声明无新分叉。不可验证分叉（谜底·偏好·用户脑内标准）出现即问；主导解释换手到第三次、或 "Better:" 型提议两次改写方案同样达反问线。超时：挂起加断点句，不代答。唯一例外："自己去找"。配套姿态：精益思考——先候选后短验证，第一次可行就沿用。

v5 起另含交叉确认与两个新类型：hook 注入关键词初判标签时，交付说明开头给【任务确认】块——任务数+每项类型与对象+hook判vs模型判对照，不一致（计划态/描述/多任务）先质询再动手，用户裁决后写分歧台账（~/.zcode/askq-divergence.jsonl）供审计复算。计划态：自报计划措辞（我计划/我打算/我可能需要）的消息无论句中含什么动词都停在计划态——只读核查与方案讨论，禁编辑落笔与"删除范围选哪个"式执行确认反问，显式下令才执行。描述：大段无委托动词的背景/粘贴内容只回应不开工。

v6 是 DSH 实机适配版（协议版本不变，仍是 v6；改动来自 DSH 上的真实使用）：①**环境前缀剥离**——DSH 会把记忆快照、AGENTS 引用、skill 目录、runtime 快照与用户话拼成同一条 prompt 送进来，闸门先按已知段头切段、丢掉环境段、只对真实用户话分类；整条都是环境内容时不注入、也不重置任务态。②**状态选址与耐久**——原先存 `os.tmpdir()`，临时目录被清理后「每会话一次」的标记归零，同一会话反复注入对账；v6 改落 `${harness}/hooks/state/`，但 DSH 的 hook 子进程跑在默认 workspace-write 沙箱里（无 agent/session 的 shell 调用取部署默认），该沙箱对工作区根与系统临时目录以外只给 RX——`~/.dsh` 带 `CodexSandboxUsers:(OI)(CI)(RX)`，写入全数 EPERM，标记同样归零。v7 改为按 cwd 优先落工作区 `<cwd>/.dsh-hooks-state`，依次回退系统临时目录、`~/.dsh/hooks/state`，每个候选先做真实探针写；目录一经选定按会话固定，并写进状态文件与临时目录索引，使不带 cwd 的调用也能找回同一份状态。③**记忆写入提醒**——记忆插件只有注入钩子、没有写入钩子，记不记全凭模型自觉（实测 31 轮会话零记忆操作）；Stop 侧兜一次底：本轮有实质落笔却没碰过记忆根时提醒一次，每会话至多一次，纯读轮不提醒。
