# 交付介质判据

- 交付物命中任一条 → 单文件 HTML（零依赖/系统字体/内联 SVG/视觉安静）：并排对比、空间结构（diff/流程图/时间线/矩阵）、视觉保真（要看颜色排版才能评）、交互必要、先扫读后下钻（可折叠/分页）、输出即工具（看板/调参面板）。
- 六条全不命中留在对话文本或 markdown；短事实、单代码片段、还要 grep 续处理的对账数据不 HTML 化。
- 版式词典 = thariqs.github.io/html-effectiveness（Thariq 画廊 20 范例；排版交付前可 browser-use 对照）。
